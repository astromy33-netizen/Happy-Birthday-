# Спасибо, Учитель

Интерактивная открытка для наставницы. Выглядит как программа: сначала виден код `thanks.js`, после кнопки «Запустить» идёт «компиляция», салют и открывается письмо с таймлайном и пожеланиями. Играет мелодия, которую страница синтезирует сама, без аудиофайлов.

Один файл `index.html`, без сборки и зависимостей. Шрифты подгружаются с Google Fonts.

## Как открыть

Откройте `index.html` в браузере или выложите папку на любой статический хостинг (Vercel, GitHub Pages).

## Как поменять имена

В конце `index.html` найдите блок:

```js
const CONFIG = { teacher: "Учитель", sender: "Ваш ученик" };
```

`teacher` попадает в заголовок («Спасибо, …!»), `sender` в подпись. Текст письма, этапы пути и пожелания лежат в HTML выше.

## Что внутри

- 3D-эффекты и анимации на CSS, фон и салют на canvas.
- Музыка через Web Audio API. Звук стартует по кнопке «Запустить», потому что браузеры не разрешают автозапуск.
- Уважает `prefers-reduced-motion`: анимации и салют отключаются.
- Адаптивная вёрстка от 360 px.
